# BIM AI Submission Copilot Demo

Clickable demo for a Hong Kong BIM + AI submission readiness pilot.

## Local Preview

```bash
python3 -m http.server 8099
```

Open `http://localhost:8099`.

## Demo Scope

- Mock IFC / Revit model upload
- BIM AI scan animation
- Submission readiness score
- Issue register with severity and owner
- AI assistant demo responses
- CITF / ESS budget simulator
- MVP difficulty and roadmap

This is a front-end demonstration only. It uses mock BIM analysis data for pitching and discovery discussions.
