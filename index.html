我們建議先做一個 BIM AI Submission Readiness Pilot，不是做 general chatbot。8-12 星期內，用你們一個真實項目測試 IFC / Revit model，AI 自動找出 BD submission、CIC data quality、ISO 19650 handover 相關風險，輸出 issue register 和修正建議。這個 pilot 可以用 CITF 包裝 adoption，你們取得內部效率，我們一起建立香港市場 case，再用 ESS 做 R&D 擴展成正式產品。

Feasibility assessment

開發難度與預算

Demo / clickable prototype 1-3 日｜HK$0-20k｜低難度

用 vibe coding 可以做到，適合見客、pitch、收需求。

MVP: IFC checker + AI report 8-12 星期｜HK$250k-650k｜中等難度

需要 IfcOpenShell、rule engine、RAG、PDF/BCF report，不一定要即時 Revit plugin。

Production: Revit plugin + CDE + audit trail 6-9 個月｜HK$1.5M-4M｜高難度

需要 BIM engineer、full-stack、LLM engineer、security、客戶真實項目測試。

Regulatory-grade checker 12-24 個月｜HK$5M-15M+｜很高難度

需要專業顧問、法規維護、模型邊界案例、責任條款，不應作第一階段承諾。

Recommended MVP scope

12-week build plan

  1. Week 1-2收 sample model、定 30-50 條 checking rules、整理香港 guideline knowledge base。
  2. Week 3-5IFC parser、data quality engine、issue classification、element ID mapping。
  3. Week 6-8AI assistant、citation answer、HTML/PDF/CSV/BCF report。
  4. Week 9-10客戶項目測試、BIM manager feedback、rule tuning。
  5. Week 11-12pilot report、ROI analysis、funding proposal package。
